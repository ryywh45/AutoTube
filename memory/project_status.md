Phase 2 (Minimal E2E Pipeline) is complete as of 2026-05-06. The full pipeline now runs end-to-end: concept → Script Agent → Storyboard Agent → TTS Agent → Video Agent, producing a rough but complete video.

Phase 3 is the current focus: Script & Storyboard Quality.

**Why:** Vertical Slice strategy — get something working first, then improve quality stage by stage.

**How to apply:** When suggesting changes or new features, orient them toward Phase 3 goals: iterative script expansion, human review gate before storyboard, improved scene splitting, real image generation (Nano Banana or similar), and multi-image selection for human review. Don't jump to Phase 4+ concerns (visual consistency, RAG) yet.
